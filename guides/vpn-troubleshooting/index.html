VPN troubleshooting guide.

VPN connections depend on your Android device, your network, the selected server, and the remote server's current availability.

If the server list loads slowly

Check that your internet connection is working, wait a short time, and try again. Public server lists can occasionally respond slowly because they depend on external services and changing server data.

If connection permission appears

Android asks for permission before an app can start a VPN tunnel. You must approve the Android VPN permission prompt for the VPN connection to begin.

If a server times out

A timeout usually means the selected server did not respond in time, is offline, is overloaded, or is blocked by a network route. Try another server rather than repeatedly attempting the same one.

If the VPN disconnects

Mobile network changes, Wi-Fi switching, battery restrictions, or a remote server restart can interrupt a VPN session. Reopen the app, check status, and connect again if needed.

If nothing works

Restart the app, switch between Wi-Fi and mobile data, check that no other VPN is active, and install the latest version from Google Play.
